# ESP32 蓝牙小车

基于 ESP32 的蓝牙遥控小车固件（Arduino IDE 开发）。小车通过经典蓝牙 SPP（串口）与手机连接，即可用蓝牙串口 App 发送指令控制前进、后退、转向和停止。

## ✨ 功能特性

- **经典蓝牙 SPP**：使用 `BluetoothSerial` 库，蓝牙名称为 `ESP32_Car`。
- **单字母状态指令**：`F` 前进 / `B` 后退 / `L` 左转 / `R` 右转 / `S` 停止。
- **自然语言命令**：支持中文和英文，例如 `前进2米`、`跑3秒`、`左转1.5秒`、`前进200cm`、`forward 2m`。
- **定时 / 定距运动**：可指定运行时间（秒）或行进距离（米/厘米），运动结束自动停车。
- **心跳循环**：持续保持当前运动状态，防止因丢帧而失控。
- **速度可调**：左右电机 PWM 占空比独立配置，便于校正直行偏差。

## 🧰 硬件需求

| 部件 | 说明 |
| --- | --- |
| ESP32 开发板 | 任意常见型号，自带 WiFi/蓝牙 |
| L298N 电机驱动模块 | 双路 H 桥，或同类可驱动两个直流电机的模块 |
| 直流电机 × 2 | 差速转向小车，左右各一个（可带轮子从动） |
| 电池组 | 按 ESP32 与电机供电要求选择 |

## 🔌 引脚定义

| 引脚 | 功能 |
| --- | --- |
| `ENA` = 16 | 左电机 PWM 使能 |
| `ENB` = 17 | 右电机 PWM 使能 |
| `IN1` = 25 | 左电机方向 1 |
| `IN2` = 26 | 左电机方向 2 |
| `IN3` = 27 | 右电机方向 1 |
| `IN4` = 14 | 右电机方向 2 |

> 如需调整，直接修改 `#define` 常量即可。

## 🚀 使用步骤

1. **烧录固件**：在 Arduino IDE 中安装 ESP32 开发板支持，选择对应的 ESP32 开发板型号，将 `sketch_may22a.ino` 编译并烧录到开发板。
2. **上电**：插上电源后，串口输出 `Bluetooth ready`，小车会先做一次前进自检（前进约 2 秒后停下）。
3. **连接蓝牙**：手机打开蓝牙，搜索并连接名为 `ESP32_Car` 的设备。
4. **发送指令**：在任意蓝牙串口助手 App 中输入指令并按发送：

   - 单字母：`F`、`B`、`L`、`R`、`S`
   - 自然语言：`前进2米`、`跑3秒`、`左转1.5秒`、`前进200cm`、`forward 2m`

## 🧠 工作原理

- **命令解析** `parseMotionCommand()`：先尝试识别单字母指令，再通过关键词匹配（如"前进"/"forward"）推断动作方向，最后解析时间（秒）或距离（米/厘米）参数。
- **距离换算**：默认 `1 秒 ≈ 0.75 米`，即 `1 米 ≈ 1.33 秒`，由常量 `METERS_PER_SECOND` 控制。
- **定时运动** `executeTimedMove()`：在一个 `while` 循环里按 20ms 心跳持续调用对应的运动函数，到达时长后自动停车。
- **主循环** `loop()`：持续读取蓝牙串口，按行（`\r`/`\n`）或长度上限切分指令并执行；平时维持当前 `currentCmd` 的运动状态。

## ⚙️ 可调参数

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `METERS_PER_SECOND` | `0.75f` | 每秒行进米数，用于距离换算 |
| `HEARTBEAT_MS` | `20` | 运动心跳间隔（毫秒） |
| `PWM_LEFT_FORWARD` | `250` | 左电机前进占空比 |
| `PWM_RIGHT_FORWARD` | `200` | 右电机前进占空比 |
| `PWM_LEFT_BACKWARD` | `250` | 左电机后退占空比 |
| `PWM_RIGHT_BACKWARD` | `10` | 右电机后退占空比 |
| `PWM_LEFT_TURN` | `250` | 左转时左电机占空比 |
| `PWM_RIGHT_TURN` | `200` | 左转时右电机占空比 |

若小车直行跑偏，可微调左右电机的 PWM 值使其走直线。
